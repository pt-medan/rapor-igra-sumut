- ✅ Always backup before deploying

- ✅ Write clear commit messages
- ✅ Deploy during off-hours
- ✅ Monitor logs after deployment

- ✅ Never edit directly on server
- ✅ Always pull before pushing

## 🆘 TROUBLESHOOTING QUICK REFERENCE

| Problem | Solution |
|---------|----------|
| Git push fails | Check URL, authenticate |
| SSH won't connect | Check credentials, contact host |
| Deploy script fails | Check logs: `tail -f storage/logs/laravel.log` |
| Backup not running | Check cron job: `crontab -l` |
| Site 500 error | Check Laravel logs |
